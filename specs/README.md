# Implementation Specifications

This directory holds durable plans and acceptance evidence for substantial
PotatoChips work. A specification describes planned or active work; it is
not an implementation or a release promise.

Follow [Planning And Completion](../AGENTS.md#planning-and-completion) for
file naming, required content, status, validation evidence, and archiving.
Small changes can be planned in chat without a specification. Allocate the
next unused number across this directory and `archive/`, starting at `001`.
Create `archive/` when the first specification is completed or abandoned.
