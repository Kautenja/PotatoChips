\manualchapter{Start with four parallel operators}{sec:start}
Formerly Boss Fight. Existing patches and presets remain compatible.

Voice 2612 combines four independently tuned Yamaha YM2612-style operators
using eight algorithms. Each operator has its own envelope. Carriers reach
the audio output; modulators change another operator's waveform.

\begin{enumerate}
\item Initialize the module. Connect either bottom output to a mixer and
turn the mixer down. The two outputs are identical mono copies.
\item Patch pitch to operator 1 V/OCT and a 5\,V keyboard gate to its GATE.
Leave the corresponding sockets on operators 2--4 empty to share these signals.
\item Keep algorithm at its default, index 7: all four operators reach the
output. Lower SAT from 127 if their sum clips.
\item Lower TL on operators 2--4 to hear operator 1 alone. Restore those
levels before trying another algorithm, where a silent carrier can mute a chain.
\end{enumerate}

The algorithm drawing uses labels 1--8; Rack's algorithm parameter uses
indices 0--7. The final drawing is the default parallel arrangement.
